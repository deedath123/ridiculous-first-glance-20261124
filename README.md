Entry for the [make.fun bounty](https://make.fun/bounty/u-po-pu-ridiculous-at-first-glance-real-by-the-second-9a97d12a): one sentence, 200 characters at most, pitching a bizarre startup idea that sounds ridiculous until you realise it would actually sell.

## The line

> We rent 10-minute naps inside parked hearses for $9 — the darkest, quietest sleep pods in the city, and funeral homes finally earn rent on vehicles that sit idle 22 hours a day.

## What it does

`main.py` (Python 3.13, standard library only) writes the pitch line to `/output/entry.txt`. It creates `/output` if needed, and the output is deterministic — byte-identical on every run (177 characters, 179 bytes, one sentence).

## Run it

```sh
python3 main.py
```

Then read `/output/entry.txt`.
